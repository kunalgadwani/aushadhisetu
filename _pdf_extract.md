 AushadhiSetu
 General Project Roadmap
 A checkpoint-based implementation plan for the Ayurvedic clinic and hospital management application
Roadmap structure
12 phases covering foundation, clinic setup, security, clinical workflows, billing, quality and
release.
Checkpoint format
Each numbered checkpoint represents a deliverable or implementation task. No
completion-status labels are included.
Project principle
Build secure clinic-level data isolation into the backend and database rules from the beginning.
Project phases
Work through the phases in sequence where practical. Some tasks may overlap, but the security and data-architecture
foundations should be established before storing real clinic records.
